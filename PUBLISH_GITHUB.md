# Публикация проекта на GitHub

1. Создайте публичный репозиторий `forma-studio` в своём аккаунте GitHub.
2. Загрузите содержимое этой папки **в корень** репозитория.
3. В Settings → Pages включите публикацию ветки main, папка `/ (root)`.
4. Убедитесь, что `https://ВАШ-ЛОГИН.github.io/forma-studio/` открывает сайт.
5. Для финального слайда укажите адрес `https://github.com/ВАШ-ЛОГИН/forma-studio`.

На GitHub Pages динамический сервер не требуется: HTML и JS работают как статические файлы.
