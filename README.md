# FORMA Studio — интерактивный конструктор домов

Учебный веб-проект: 2D-планировка, 3D-визуализация, создание помещений до двух этажей, учебные инженерные проверки и экспорт в FreeCAD (`.FCStd`).

## Запуск

1. Скачайте репозиторий как ZIP или клонируйте его.
2. Распакуйте файлы в одну папку.
3. Откройте `index.html` в современном браузере. На GitHub Pages сайт открывается по ссылке публикации.

Никакие Python, Node.js, npm и сервер для обычного запуска не требуются. На РЕД ОС применяется тот же принцип.

## Файлы

- `index.html` — оформление страницы, в том числе резервный встроенный код приложения для запуска без внешнего `app.js`.
- `app.js` — 2D/3D-редактор, управление, экспорт FreeCAD.
- `physics.js` — отдельный сменный движок учебных расчётов.

## Как заменить физику

См. [PHYSICS_SWAP.md](PHYSICS_SWAP.md). Основной контракт: `window.FormaPhysics.calculatePhysics(project)`.

## Что показывать на защите

Создание комнаты → перемещение и изменение размеров → 3D внутри и снаружи → инженерные предупреждения → скачивание `.FCStd`.

## Ограничения

Расчёты являются демонстрационными. Это не рабочая проектная документация и не подтверждение безопасности здания. Файл FCStd проверялся структурно, но совместимость со всеми версиями FreeCAD и РЕД ОС требует отдельного испытания.

## Публикация через GitHub Pages

Откройте Settings → Pages → Deploy from a branch → `main` / `(root)` → Save. Адрес станет доступен после публикации; его можно добавить на финальный слайд презентации.
