# Замена вычислительного движка FORMA Studio

## Один файл

Откройте `physics.js`. Для замены расчётов отредактируйте реализацию `calculatePhysics(project)`; интерфейс должен остаться прежним.

```javascript
window.FormaPhysics = {
  calculatePhysics(project) {
    return {
      metrics: {
        groundArea: 0, upperArea: 0, totalArea: 0, rooms: 0,
        totalWallLength: 0, loadKN: 0, soilPressureKPa: 0,
        soilUtilization: 0, estimatedHeatKW: 0,
        criticalCount: 0, warningCount: 0
      },
      issues: [{ severity: 'info', title: 'Расчёт подключён', detail: 'Демонстрационный вывод', tag: 'engine' }],
      heating: [], assumptions: ['Тестовый движок']
    };
  }
};
```

Это **пример контракта**, а не полноценный физический расчёт. Для реального подключения сохраняйте реальные данные из входного `project`, единицы измерения и типы полей. На практике безопаснее заменить только функцию в существующем IIFE-файле `physics.js`, оставив его оболочку.

## Возвращаемая структура

- `metrics`: сводные показатели для панели интерфейса.
- `issues`: массив предупреждений. `severity` = `critical`, `warning`, `success` или `info`.
- `heating`: расчёты по помещениям (массив объектов).
- `assumptions`: список допущений и условий применимости.

## Проверка подключения

1. Измените `physics.js` (например, добавьте новое `issues` с `severity:'info'`).
2. Сохраните файл и перезагрузите `index.html` без кеша.
3. Откройте панель «Анализ» и убедитесь, что появилось новое сообщение.
4. Проверьте результаты при изменении размеров комнаты и материала стен.

## Требования к промышленному модулю

Применяйте проверенные нормативные методы, учёт грунтов, снеговых/ветровых воздействий и сочетаний нагрузок; выполняйте верификацию на эталонных задачах. До инженерной аттестации не используйте результаты для строительства.
